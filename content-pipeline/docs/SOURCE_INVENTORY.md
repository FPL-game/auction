## Environment note affecting every other originally-proposed source

This sandboxed session's network egress is restricted to an **allowlist**, not a blocklist: essentially GitHub (`github.com` git-clone, `raw.githubusercontent.com`, `api.github.com` for attached repos) plus package registries (PyPI, npm, etc.) and Anthropic's own API. Confirmed blocked, at the proxy-policy level (`gateway answered 403 to CONNECT`), for every one of these: `fantasy.premierleague.com`, `api.clubelo.com`, `www.thesportsdb.com`, `api.football-data.org`, `understat.com`, `www.football-data.co.uk`, `huggingface.co`, `figshare.com`, `doi.org`, `www.nature.com`. This is an org-level policy for this specific sandboxed session, not a per-source licensing issue, and per the proxy's own guidance such denials should be reported, not routed around — which is what this document does. **Practical effect: for now, this pipeline can only use sources that are hosted on GitHub itself** (a GitHub org's repo, or a GitHub-hosted mirror/repackage of an otherwise-open dataset — e.g. `koenvo/wyscout-soccer-match-event-dataset` for the Pappalardo/Wyscout data, which was located but not yet pulled this session).
